## Highlighted Projects

### [MiracleDesk](https://github.com/premd06/miracledesk) — Brokerage Dashboard (building now)

Realtors log their deals and the app does the commission math: gross, referral fee, brokerage split, 13% HST, agent net. Agents see their own deals and money, brokers see office totals, a leaderboard, and closings this month. React + Express + SQLite, all sample data while I build it.

---

### [davehomes.ca](https://davehomes.ca) — Pre-construction Site for My Buyer Clients

30+ townhouse and detached projects across the GTA, Niagara, and Kitchener-Waterloo-Cambridge, with a map of every project, 10 years of home price data, and a Canadian mortgage calculator. Plain HTML, CSS, and JavaScript, no framework. I built it because I was answering the same buyer questions over and over.

---

### [seo-dashboard](https://github.com/premd06/seo-dashboard) — Website Performance Dashboard

Tracks how davehomes.ca is doing: PageSpeed scores, SEO checks, that kind of thing. A Python script pulls data from Google's PageSpeed API into SQLite, a Node/Express API serves it, and a React page displays it. This was my first real frontend + backend project.

---

### [halal-eats](https://github.com/premd06/halal-eats) — GTA Halal Restaurant Finder (on pause)

A finder that shows how halal a place actually is: certified, full halal menu, or just some halal options, with the basis and the last date I verified it. React + Leaflet. On pause while I build MiracleDesk.
